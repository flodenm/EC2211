# EC2211 course assistant sources

This repository holds material for the [EC2211 Course Assistant](https://github.com/copilot/spaces/flodenm/1).

- `assistant_sources/Fall_2026/`: current, authoritative lecture notes and voluntary problem sets.
- `assistant_sources/Fall_2025/`: archived reference material; current course rules must not be inferred from it.
- `assistant_sources/EC2211_AGENT_GUIDE.md`: tutoring and source-use rules.
- `assistant_sources/EC2211_Fall2026_SOURCE_INDEX.md`: lecture and problem-set filename index.

The public course website remains in `flodenm/martin_floden_website`; this repository is for the assistant's source material.
