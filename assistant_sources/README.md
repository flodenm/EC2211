# EC2211 course-assistant sources

This directory contains machine-readable course material for the EC2211 course assistant.

## Version policy

- `Fall_2026` is the current and authoritative course edition when material exists there.
- `Fall_2025` is archival reference material. An answer based only on this directory must say so explicitly and warn that details may have changed.
- Never combine notation, deadlines, assessment rules or exercises from different course editions without clearly identifying the edition of each source.
- Cite the course edition, document name and frame or section title whenever possible.

## Content policy

- Lecture-source files preserve text, equations, links and document structure from the lecture sources.
- Figure filenames and explanatory notes are retained when available. Consult the original lecture slides for the visual itself.
- The current problem-set files listed in the source index contain questions only. Suggested solutions are excluded from those indexed files.
- Administrative information in older lecture notes is historical, not current guidance.

## Included Fall 2026 material

- LN00a–LN11, including separate files for LN5a/LN5b and LN11a/LN11b.
- Problem Sets 1–4, without suggested solutions.
- `EC2211_Fall2026_SOURCE_INDEX.md` maps common lecture and problem-set aliases to exact filenames.

## Included Fall 2025 material

Fall 2025 material is retained only as an archive for additional explanation or practice. It does not establish current course rules, coverage, notation or assignment content.
